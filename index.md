# Menu bar calendar

Menu bar calendar is a small personal tool that shows my Google Calendar in the macOS menu bar. It is a plugin for [SwiftBar](https://github.com/swiftbar/SwiftBar) and runs only on my own Mac.

## What it does

- Shows the coming week as a list, with a small picture of each day on hover.
- Shows this week and next as a single picture, with free and busy time.
- Shows each event in the colour it has in Google Calendar.

## How it uses Google

The tool asks for one permission: read-only access to Google Calendar. It uses this to read event times, titles, locations, notes and colours so it can draw them in the menu bar. It cannot create, change or delete anything.

## Who it is for

This is a private tool for one person. It is not a service, it has no accounts and it is not offered to the public.
